## ScoutChase

### AI-assisted prospecting and outreach

ScoutChase is a working full-stack product prototype built around a simple idea:

```text
PLAYBOOK
   ↓
SCOUT
Discover · Research · Rank
   ↓
HUMAN APPROVAL
   ↓
CHASE
Draft · Follow Up · Assist
   ↓
CONVERSATION
```

Scout researches and ranks opportunities.

**The user decides which opportunities move forward.**

Chase helps turn approved opportunities into personalized outreach and follow-up.

[![ScoutChase](https://raw.githubusercontent.com/mtmclennan/ScoutChase-showcase/main/images/screens/dashboard.png)](https://github.com/mtmclennan/ScoutChase-showcase)

The same core system supports:

- sales prospecting
- job search
- recruiting

The playbook changes what Scout searches for, what signals matter, and how Chase communicates.

### Engineering highlights

- AI-assisted research and ranking
- Structured playbooks
- External-source adapters
- Job and company discovery
- Matching and qualification logic
- Human-in-the-loop approval
- Outreach drafting
- Reply assistance
- Prospect pipeline
- Persistent application data
- Automated workflow testing

**Stack:** Next.js · React · TypeScript · PostgreSQL · Prisma · Clerk · Vitest · Playwright · Docker

**Demonstrates:** AI product development · external data integration · prospecting systems · workflow design · human-in-the-loop automation
